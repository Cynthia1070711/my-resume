Philosophy & Agent Architecture

第一性原理思考與 AI Agent 開發哲學

在程式碼生成邊際成本趨近於零的時代，工程師的核心價值在於解構真實業務場景、定義高邊界標準與駕馭 AI 工作流。

第一性原理 (First-Principles Thinking)

絕不盲從厚重架構或業界流行框架。當市面上的軟體方案為 90% 不需要的功能收取高額授權費時，我選擇將問題拆解至最原子層面：

  • ✓ YDA 輪播：門市只需要全螢幕循環展示圖片與影片，純靜態 Web + Android 即是最優解。
  • ✓ 辦公工具：資料運算完全可在瀏覽器記憶體完成，無須後端伺服器，達成零資料外洩風險。
  • ✓ 審查輔助：AI 全自動識別訓練週期長且開銷大，先以 Canvas/DOM 懸浮外掛達成立即降維減輕人眼疲勞。
回歸真實業務本質需求，以極簡技術棧解決高頻痛點，剔除過度設計。
